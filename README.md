# Quiz Live

Des quiz en direct, façon Kahoot : le **grand écran** présente, les **téléphones** répondent (sans compte ni appli), le **classement** s'anime en direct.

- Catalogue : https://projafr.github.io/quiz-live/
- Trash Match (tri des déchets, Grand Nancy) : https://projafr.github.io/quiz-live/tri-dechets/

## Jouer
1. Sur l'ordinateur relié au vidéoprojecteur : ouvrir le quiz, cliquer « Je présente sur le grand écran », touche **F** pour le plein écran.
2. Les joueurs **coupent le wifi**, passent en 4G/5G et scannent le QR code.
3. **Espace**, **Entrée** ou **→** pour avancer (une télécommande de présentation marche aussi).

## Créer un nouveau quiz
Demander à Claude : « Crée un quiz Quiz Live sur … ». Chaque quiz est un dossier `quizzes/<nom>/` (contenu + dessins) ; le moteur et les thèmes sont partagés.
